# Project Mandates

- **No commit to main branch:** Always use a feature branch and create a Pull Request.
- **Cost Optimization:** Prioritize strategies that optimize Firebase costs (e.g., efficient queries, caching).
- **Verification First:** Only commit changes after they have been thoroughly tested and validated.
- **Atomic Commits:** Prefer small, focused, atomic commits over large, monolithic changes.
- **Documentation:** Keep all project documentation up-to-date with any code or architectural changes.
