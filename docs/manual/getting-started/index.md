# Aloittaminen

Tervetuloa Kiekuu-sovellukseen! Tämä osio opastaa sinut alkuun.

## Sisältö

- [Rekisteröityminen](signup) — Luo tili tai kokeile ilman
- [Ensimmäiset askeleet](first-steps) — Vastaukset, tasot ja edistyminen
- [UKK](faq) — Usein kysytyt kysymykset

---

## Nopea alku

Jos haluat kokeilla heti:

1. Avaa [kiekuu.apinalauma.fi](https://kiekuu.apinalauma.fi)
2. Klikkaa **"Aloita oppiminen"**
3. Vastaa ensimmäiseen kysymykseen
4. Luo tili ensimmäisen tason jälkeen (tietosi tallentuvat)

> 💡 **Vinkki:** Et tarvitse tiliä kokeillaksesi, mutta rekisteröityminen tallentaa edistymisesi.
