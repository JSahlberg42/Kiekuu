Tasojärjestelmä (Arvot)

Suorita kysymyksiä edetäksesi tasoilla:

  1. Harjoittelija — Perusteet ✅ (aloitat tästä)
  2. Nuorempi sammutusmies — Peruskurssin alku
  3. Sammutusmies — Peruskurssi suoritettu
  4. Vanhempi sammutusmies — Syventävä osaaminen
  5. Ryhmänjohtaja — Johtamistaidot
  6. Palokunnan päällikkö — Ylin taso

AI Tutor — Älykäs Tutor

Kun vastaat väärin, Kiekuu käyttää Gemini 3.7 Flash -tekoälyä selittämään oikean vastauksen.

Mitä saat:

  • ✅ Yksinkertainen selitys
  • ✅ Viittaus OPS-materiaaliin
  • ✅ Käytännön esimerkki

Esimerkki:

Kysymys: Mikä on alkusammutuksen ensisijainen tavoite?

Vastauksesi: C (väärin)

AI Tutor: Alkusammutuksen tavoite on henkilövahinkojen ehkäisy. Pelastusopiston mukaan (OPS 2026, s. 15) henkilövahinkojen ehkäisy on aina ensisijainen tavoite. Palo voidaan sammuttaa, mutta loukkaantunutta ihmistä ei voi korvata.
