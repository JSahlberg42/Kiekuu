# Harjoittelija

Ensimmäinen taso Kiekuussa — aloitat tästä.

---

## Yleiskatsaus

| Ominaisuus | Tiedot |
|-------------|---------|
| **Taso** | 1 / 6 |
| **Edellytykset** | Ei vaatimuksia |
| **Tavoite** | Tutustu palokuntatoiminnan perusteisiin |

---

## Mitä opit

### Perusosaaminen

Tämä taso kattaa palokuntatoiminnan perusteet:

1. **Turvallisuus** — Työturvallisuus, henkilökohtaiset suojavarusteet
2. **Yksikkötunnukset** — Palokunnan tunnukset ja rakenteet
3. **Viestintä** — Perusradiosanasto (VIRVE)
4. **Ensiapu** — Perusensiavun periaatteet

### Aihealueet

| Aihe | Esimerkki sisältö |
|------|-------------------|
| Työturvallisuus | Suojainten käyttö, vaaratekijät |
| Yksikkörakenne | VPK:n organisaatio, hälytysjärjestys |
| VIRVE-perusteet | Radion käyttö, tilanneraportti |
| EA1-perusteet | Hätäensiapu,elvytys |
