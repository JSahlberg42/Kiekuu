Mitä opit

Syventävä osaaminen

Tämä taso kattaa erikoisosaamisen ja syventävät taidot:

1. Vaaralliset aineet — Kemikaalit, öljyt 2. Pintapelastus — Veden pinnalla toimiminen 3. Sukellustoiminta — Kemikaalisukellus 4. Öljyntorjunta — Ympäristönsuojelu

Aihealueet

| Aihe | Esimerkki sisältö | |------|-------------------| | VA-henkilöstö | Vaarallisten aineiden tunnistus | | Kemikaalisukellus | Sukellus suojeluvarustein | | Öljyntorjunta | Ympäristönsuojelu, keräily | | Pintapelastus | Vedessä toimiminen, pelastus |
