---

## Mitä opit

### Hallinnollinen johtaminen

Tämä taso kattaa hallinnolliset vastuut ja johtamisen:

1. **Lainsäädäntö** — Pelastuslainsäädäntö, vastuut
2. **Hallinto** — Talous, henkilöstö
3. **Koulutus** — Koulutuksen suunnittelu
4. **Yhteistyö** — Viranomaisyhteistyö

### Aihealueet

| Aihe | Esimerkki sisältö |
|------|-------------------|
| Lainsäädäntö | Pelastuslaki, vastuut |
| Hallinto | Talous, henkilöstöhallinto |
| Koulutus | Koulutussuunnittelu, OPS |
| Verkostot | Viranomaisyhteistyö |
