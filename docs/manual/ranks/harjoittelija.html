Mitä opit

Perusosaaminen

Tämä taso kattaa palokuntatoiminnan perusteet:

1. Turvallisuus — Työturvallisuus, henkilökohtaiset suojavarusteet 2. Yksikkötunnukset — Palokunnan tunnukset ja rakenteet 3. Viestintä — Perusradiosanasto (VIRVE) 4. Ensiapu — Perusensiavun periaatteet

Aihealueet

| Aihe | Esimerkki sisältö | |------|-------------------| | Työturvallisuus | Suojainten käyttö, vaaratekijät | | Yksikkörakenne | VPK:n organisaatio, hälytysjärjestys | | VIRVE-perusteet | Radion käyttö, tilanneraportti | | EA1-perusteet | Hätäensiapu,elvytys |
