# Ryhmänjohtaja

Viides taso — Johtamistaidot ja taktinen ajattelu.

---

## Yleiskatsaus

| Ominaisuus | Tiedot |
|-------------|---------|
| **Taso** | 5 / 6 |
| **Edellytykset** | Vanhempi sammutusmies suoritettu |
| **Tavoite** | Johtaminen ja taktinen päätöksenteko |

---

## Mitä opit

### Johtamistaidot

Tämä taso keskittyy johtamiseen ja taktiseen ajatteluun:

1. **Taktiikka** — Toiminnan suunnittelu ja johtaminen
2. **VIRVE-viestintä** — Taktinen johtaminen
3. **Tilannearviointi** — Nopea päätöksenteko
4. **Ryhmänjohtaminen** — Ihmisten johtaminen

### Aihealueet

| Aihe | Esimerkki sisältö |
|------|-------------------|
| Taktiikka | Toimintamallit, resurssien käyttö |
| Johtaminen | Ryhmän motivointi, vastuunjako |
| VIRVE | Tilanneraportit, käskyt |
| Tilannearviointi | Riskiarvio, päätöksenteko |
